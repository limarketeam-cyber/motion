# Instagram templates (ruby.explains)
Static, full-size (1080px) HTML templates built from the components in `components/`.
- term-card.html — text-only single-term post (grid background, formula box)
- term-card-photo.html — single-term post with a real photo on top
- reels-cover.html — 1080×1920; keep every word inside the dashed 4:5 crop (285–1635px). Hide the guide before export.
- highlight-covers.html — six category circles. For upload, place one circle's icon centred on a 1080×1920 ink canvas.
